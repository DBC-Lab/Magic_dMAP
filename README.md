# MAGIC-dMAP

**MAGIC-dMAP** (Multiple Atlases and Granularities—Integrating Connectivity Dynamics for Multisite Autism Prediction) is a deep learning framework for autism spectrum disorder (ASD) classification using resting-state functional MRI (rs-fMRI). It integrates multi-atlas dynamic functional connectivity features at coarse and fine granularities through adaptive fusion and triplet metric learning to improve classification across unseen imaging sites.

The framework was evaluated on **1,020 subjects from 17 sites in the ABIDE-I dataset** using Leave-One-Site-Out (LOSO) cross-validation. This repository provides the implementation of MAGIC-dMAP, including data preprocessing, feature extraction, model training, and evaluation.
