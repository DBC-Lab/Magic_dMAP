# Atlas references and file provenance

The reference implementation uses the following five atlas keys. Atlas binaries are external inputs and are not redistributed here.

| Key | Expected file | Common reference |
|---|---|---|
| `aal` | `aal.nii.gz` | Tzourio-Mazoyer et al., 2002, *NeuroImage*, 15, 273–289. DOI: `10.1006/nimg.2001.0978` |
| `cc400` | `cc400.nii.gz` | Craddock et al., 2012, *Human Brain Mapping*, 33, 1914–1928. DOI: `10.1002/hbm.21333` |
| `dosenbach160` | `dosenbach160.nii.gz` | Dosenbach et al., 2010, *PNAS*, 107, 1107–1112. DOI: `10.1073/pnas.0915507107` |
| `ez` | `ez.nii.gz` | Eickhoff et al., 2005, *NeuroImage*, 25, 1325–1335. DOI: `10.1016/j.neuroimage.2004.12.034` |
| `ho` | `ho.nii.gz` | Smith et al., 2004, *NeuroImage*, 23 Suppl. 1, S208–S219. DOI: `10.1016/j.neuroimage.2004.07.051` |

The key `ez` is retained because it is the identifier in the source data and model code; the manuscript describes this atlas as Eickhoff–Zilles.
